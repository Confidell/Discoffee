# DISCOFFEE - CAFETERIA TECNOLOGICA

## Sobre o projeto

    O DISCOFFEE é um sistema de cafeteria desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de oferecer uma plataforma para visualização de produtos, personalização de pedidos e gerenciamento de compras.

    O projeto foi desenvolvido utilizando ASP.NET Core MVC, com integração a um banco de dados MySQL.

## Estrutura do projeto

    O projeto está organizado em pastas, cada uma responsável por uma parte específica do sistema, facilitando a manutenção e a organização do código.

    Discoffee/
    │
    ├── Areas/                         # Áreas separadas por tipo de usuário (Cliente, Gerencia)
    │
    ├── Banco/                         # Scripts e arquivos do banco de dados
    │
    ├── Controllers/                   # Controladores responsáveis pelas requisições
    │
    ├── Models/                        # Classes que representam os dados do sistema
    │
    ├── Repository/                    # Acesso e operações no banco de dados
    │
    ├── Sessao/                        # Gerenciamento de dados da sessão (Carrinho)
    │
    ├── ViewModels/                    # Modelos utilizados para transportar dados às Views
    │
    ├── Views/                         # Páginas e interfaces do sistema
    │
    ├── wwwroot/                       # Arquivos estáticos (CSS, JS, Assets, Imagens, Icons)
    │
    ├── .gitignore                     # Arquivos ignorados pelo Git
    │
    ├── appsettings.json               # Configurações gerais da aplicação
    │
    ├── Program.cs                     # Inicialização e configuração da aplicação
    │
    └── README.md                      # Documentação do projeto
